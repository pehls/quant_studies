Arbitragem Estatística

Modelos, Implementação e Gestão de Risco

A Arbitragem Estatística (StatArb) é uma classe de estratégias de negociação de curto prazo que emprega modelos estatísticos e econométricos para identificar ineficiências de preços temporárias entre títulos relacionados. A filosofia central da StatArb é construir um portfólio, muitas vezes contendo centenas ou milhares de posições compradas e vendidas, onde cada posição representa uma aposta na convergência de uma relação estatística.

No cerne de quase toda estratégia de arbitragem estatística está uma única e poderosa suposição econômica: a hipótese de reversão à média. Quando o valor atual de uma relação se desvia significativamente da média, uma oportunidade de negociação é sinalizada, apostando em seu retorno ao equilíbrio.

O Fluxo de Trabalho Canônico de Pairs Trading

Pairs trading é a estratégia arquetípica de arbitragem estatística. É uma estratégia de mercado neutro que combina uma posição comprada em um título com uma posição vendida em outro título relacionado e historicamente correlacionado.

Implementação de um Pairs Trade Simples em Python

O código a seguir demonstra o fluxo de trabalho completo: adquirir dados para um par clássico (Coca-Cola e PepsiCo), calcular o spread usando regressão OLS, normalizá-lo com um Z-score e plotar os resultados para visualizar potenciais sinais de negociação.


import yfinance as yf
import pandas as pd
import numpy as np
import statsmodels.api as sm

# 1. Aquisição de Dados
ticker1 = 'KO'; ticker2 = 'PEP'
start_date = '2018-01-01'; end_date = '2023-12-31'
prices = yf.download([ticker1, ticker2], start=start_date, end=end_date)['Adj Close'].dropna()

# 2. Cálculo do Spread usando Regressão OLS
y = prices['PEP']; x = prices['KO']
model = sm.OLS(y, sm.add_constant(x)).fit()
beta = model.params['KO']
spread = prices['PEP'] - (beta * prices['KO'] + model.params['const'])

# 3. Normalização com Z-Score
lookback_window = 30
z_score = (spread - spread.rolling(window=lookback_window).mean()) / spread.rolling(window=lookback_window).std()

A Fundação Econométrica: Testando a Cointegração

Um erro crítico é confundir correlação com cointegração. A **correlação** mede o grau em que os retornos de dois ativos se movem juntos. A **cointegração**, por outro lado, é uma propriedade de duas ou mais séries temporais não estacionárias (como preços de ativos). Elas são ditas cointegradas se alguma combinação linear delas for estacionária. Essa combinação linear estacionária é precisamente o spread de reversão à média que um trader de pares procura.

Teste de Engle-Granger com `statsmodels`


import yfinance as yf
import pandas as pd
from statsmodels.tsa.stattools import coint

# Usar os mesmos dados de KO e PEP
prices = yf.download(['KO', 'PEP'], start='2018-01-01', end='2023-12-31')['Adj Close'].dropna()

# Realizar o teste de cointegração de Engle-Granger
# A hipótese nula é que NÃO há cointegração.
coint_test_result = coint(prices['PEP'], prices['KO'])
p_value = coint_test_result[1]

print(f"Teste de Cointegração para PEP e KO:")
print(f"P-valor: {p_value:.4f}")

if p_value < 0.05:
    print("\nResultado: As séries são provavelmente cointegradas (p-valor < 0.05).")
else:
    print("\nResultado: As séries não são cointegradas (p-valor >= 0.05).")

Técnicas Avançadas de Modelagem de Spread

Processo de Ornstein-Uhlenbeck (OU)

O processo OU é uma equação diferencial estocástica que modela formalmente o comportamento de reversão à média de um spread, caracterizado por uma velocidade de reversão ($\theta$), uma média de longo prazo ($\mu$) e uma volatilidade ($\sigma$). Uma métrica útil derivada do processo OU é a meia-vida de reversão à média, que estima o tempo esperado para que um desvio da média decaia pela metade.

Cobertura Dinâmica com o Filtro de Kalman

Uma fraqueza significativa dos modelos estáticos é a suposição de uma razão de hedge constante, $\beta$. O Filtro de Kalman é um algoritmo recursivo que aborda esse problema, permitindo que a razão de hedge seja atualizada dinamicamente em tempo real, adaptando-se às mudanças nas condições de mercado.


from pykalman import KalmanFilter
import yfinance as yf
import pandas as pd
import numpy as np

# Exemplo com GLD (ETF de Ouro) e GDX (ETF de Mineradoras de Ouro)
prices_kf = yf.download(['GLD', 'GDX'], start='2018-01-01', end='2023-12-31')['Adj Close'].dropna()

# Configuração do Filtro de Kalman
obs_matrix = np.vstack([prices_kf['GLD'], np.ones(prices_kf.shape[0])]).T[:, np.newaxis, :]
kf = KalmanFilter(
    n_dim_obs=1, n_dim_state=2,
    initial_state_mean=np.zeros(2),
    transition_matrices=np.eye(2),
    observation_matrices=obs_matrix,
    observation_covariance=1.0,
    transition_covariance=1e-5 / (1 - 1e-5) * np.eye(2)
)

# Executar o filtro
state_means, _ = kf.filter(prices_kf['GDX'].values)
dynamic_hedge_ratio = pd.Series(state_means[:, 0], index=prices_kf.index)

Frameworks Robustos de Gestão de Risco

O sucesso a longo prazo na arbitragem estatística é determinado pela robustez dos sistemas de gestão de risco. Os riscos incluem risco de modelo, mudanças de regime de mercado, risco de execução e risco de liquidez.

A mitigação desses riscos requer uma abordagem multifacetada, incluindo dimensionamento de posição inteligente, stop-losses rigorosos e diversificação em nível de portfólio.

Dimensionamento de Posição e Stop-Losses

O dimensionamento por volatilidade ajusta o tamanho da posição para ser inversamente proporcional à volatilidade do spread, mantendo o risco em dólar de cada negociação relativamente constante. Os stop-losses são a defesa final contra a falha do modelo. Eles podem ser baseados em um limiar máximo de Z-score, um drawdown máximo ou um stop baseado no tempo relacionado à meia-vida do spread.
