O Framework Bayesiano: Do Conhecimento Prévio ao Posterior

No coração da estatística Bayesiana está um teorema simples, mas profundo, que fornece a base matemática para aprender com os dados. Para fins de modelagem estatística, onde estamos interessados em aprender sobre os parâmetros do modelo, $\theta$, a partir de dados observados, $D$, o teorema é expresso como:

$P(\theta|D) = \frac{P(D|\theta) \cdot P(\theta)}{P(D)}$
  • Probabilidade Posterior, $P(\theta|D)$: Nossa crença atualizada sobre os parâmetros após observar os dados.
  • Verossimilhança (Likelihood), $P(D|\theta)$: A probabilidade de observar os dados, dado um conjunto específico de parâmetros.
  • Probabilidade a Priori, $P(\theta)$: Nossas crenças iniciais sobre os parâmetros antes de ver os dados.
  • Evidência, $P(D)$: A probabilidade dos dados, servindo como uma constante de normalização.

Exemplo Prático: Teste Diagnóstico


def bayes_theorem_diagnostic(sensitivity, specificity, prevalence):
    """
    Calcula a probabilidade posterior de uma condição (ex: ser um usuário de droga)
    dado um resultado de teste positivo, usando o Teorema de Bayes.
    """
    p_pos_given_user = sensitivity
    p_user = prevalence
    p_pos_given_non_user = 1 - specificity
    p_non_user = 1 - prevalence

    numerator = p_pos_given_user * p_user
    denominator = (p_pos_given_user * p_user) + (p_pos_given_non_user * p_non_user)
    
    posterior = numerator / denominator
    return posterior

# Parâmetros para o cenário de teste de drogas
sensitivity = 0.97
specificity = 0.95
prevalence = 0.005

prob_user_given_positive = bayes_theorem_diagnostic(sensitivity, specificity, prevalence)
print(f"A probabilidade de um indivíduo ser usuário, dado um teste positivo, é: {prob_user_given_positive:.1%}")

Tornando a Inferência Bayesiana Prática: A Revolução Computacional

Programação Probabilística com PyMC

Linguagens de Programação Probabilística (PPLs) como o PyMC abstraem a complexidade da implementação do MCMC. O usuário especifica os componentes de um modelo Bayesiano — os priors e a verossimilhança — e o backend do PyMC executa automaticamente um algoritmo de amostragem MCMC eficiente (como o NUTS) para extrair amostras da distribuição posterior.


import pymc as pm
import numpy as np
import arviz as az

# Gerar dados sintéticos para y = alpha + beta*x + ruído
np.random.seed(42)
true_alpha = 2.5; true_beta = 1.7; true_sigma = 1.0
x = np.linspace(0, 1, 100)
y = true_alpha + true_beta * x + np.random.normal(0, true_sigma, size=100)

# Definição do Modelo PyMC
with pm.Model() as linear_model:
    alpha = pm.Normal('alpha', mu=0, sigma=10)
    beta = pm.Normal('beta', mu=0, sigma=10)
    sigma = pm.HalfNormal('sigma', sigma=5)
    mu = alpha + beta * x
    Y_obs = pm.Normal('Y_obs', mu=mu, sigma=sigma, observed=y)
