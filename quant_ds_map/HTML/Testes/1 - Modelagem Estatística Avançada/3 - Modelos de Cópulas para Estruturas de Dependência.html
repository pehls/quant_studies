Modelos de Cópulas para Estruturas de Dependência

Além da Correlação Linear em Finanças

A dependência entre ativos é um pilar da teoria de portfólio e da gestão de risco. Por décadas, a ferramenta principal para modelar essa dependência foi a correlação linear. No entanto, a confiança na correlação é perigosa, pois fornece uma imagem incompleta do risco, especialmente durante períodos de estresse de mercado.

O Pilar Teórico: Teorema de Sklar

O Teorema de Sklar é a base matemática da modelagem de cópulas. Ele afirma que qualquer distribuição conjunta multivariada pode ser decomposta em suas distribuições marginais univariadas e uma cópula que descreve sua estrutura de dependência.

$F(x_1, \dots, x_d) = C(F_1(x_1), \dots, F_d(x_d))$

Exemplo em Python: Construindo uma Distribuição Conjunta


import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns
from scipy import stats
from statsmodels.distributions.copula.api import GaussianCopula, CopulaDistribution

# 1. Definir duas distribuições marginais diferentes
marginals = [stats.norm(loc=0, scale=1), stats.t(df=5)]

# 2. Definir uma cópula para descrever a estrutura de dependência
copula = GaussianCopula(corr=0.7)

# 3. Criar a distribuição conjunta "acoplando" as marginais com a cópula
joint_dist = CopulaDistribution(copula=copula, marginals=marginals)

# 4. Gerar 2000 amostras da nova distribuição conjunta
joint_samples = joint_dist.rvs(2000, random_state=42)

Taxonomia das Famílias de Cópulas e Dependência de Cauda

Para aplicações financeiras, a propriedade mais crítica de uma cópula é a dependência de cauda, que descreve a tendência das variáveis de sofrerem eventos extremos juntas.
