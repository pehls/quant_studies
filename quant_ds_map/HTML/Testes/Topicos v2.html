Informações Compiladas dos Materiais de Referência

1. Negociação Algorítmica e Machine Learning

  • A negociação algorítmica utiliza programas de computador que executam algoritmos para automatizar elementos de uma estratégia de trading.
  • Algoritmos são sequências de passos ou regras projetadas para atingir um objetivo, facilitando a otimização em todo o processo de investimento, desde a geração de ideias até a alocação de ativos, execução de trades e gestão de risco.
  • Novas fontes de dados alternativos, resultantes da revolução do big data, incluem informações de indivíduos, processos de negócios e sensores (como satélites ou dispositivos de localização GPS). Estes dados fornecem inputs críticos para estratégias de trading algorítmico que utilizam Machine Learning (ML).

2. Ciência de Dados para Economia e Finanças

2.1 Processamento de Dados Textuais e NLP

2.1.1 Conceitos e Aplicações

  • Dados textuais pertencem à categoria de dados não estruturados. O aprendizado a partir desses dados complexos pode gerar padrões descritivos mais concisos e semanticamente ricos, que melhor refletem suas propriedades intrínsecas.
  • Tecnologias como a Web Semântica (também conhecida como "Web 3.0"), incluindo Processamento de Linguagem Natural (NLP) e Recuperação de Informação, foram criadas para facilitar o acesso a uma vasta quantidade de informações textuais.
  • A Web Semântica permite que máquinas "compreendam" e respondam a requisições humanas complexas baseadas em seu significado, exigindo que as fontes de informação relevantes sejam semanticamente estruturadas.
  • Linked Open Data (LOD) ganhou impulso como uma prática recomendada para promover o compartilhamento e a publicação de dados estruturados na Web Semântica, utilizando URIs, RDF e OWL.
  • Em nossa sociedade moderna, quase todos os eventos, processos e decisões em uma corporação são documentados por meio de comunicação escrita interna, registros legais ou notícias de negócios e finanças. O conhecimento valioso nessas coleções não é diretamente acessível por computadores por consistir principalmente em texto não estruturado.
  • Métodos modernos de NLP podem ser usados para extrair dados estruturados de texto, como menções de empresas e seus relacionamentos. Isso é fundamental para a construção de um grafo de conhecimento (KG) com todas as informações extraídas.
  • A tarefa de transformar dados textuais em sinais numéricos úteis requer a aplicação de técnicas adequadas de mineração de texto.
  • A **análise de sentimento de textos financeiros** é utilizada para obter insights de dados empíricos para a construção de modelos de previsão ou sistemas de trading.
  • **Previsão econômica** pode ser realizada utilizando texto de jornais.

2.1.2 Ferramentas Específicas de NLP

  • Para coletar dados estruturados de transcrições não estruturadas, pode-se usar expressões regulares em conjunto com Beautiful Soup. Isso permite coletar informações detalhadas sobre a empresa e o momento da chamada de resultados, bem como atribuir declarações a analistas e representantes da empresa.
  • TextBlob é uma biblioteca Python que oferece uma API simples para tarefas comuns de NLP, construída sobre o Natural Language Toolkit (NLTK) e as bibliotecas de web mining Pattern. Facilita o POS tagging, extração de frases nominais, análise de sentimento, classificação e tradução, entre outros.
  • A visualização da dependência sintática pode ser feita em um navegador ou notebook usando `displacy.render()`. A função `spacy.explain()` pode fornecer insights adicionais sobre o significado de atributos (ex: "VBZ" para "verb, 3rd person singular present").
  • O pacote openNLP e o modelo Vader (para análise de sentimento de texto de mídia social) são referências na área.
  • A ferramenta "Word power" é uma abordagem para análise de conteúdo.
  • A criação de uma lista de stop words pode ser realizada manualmente com `spaCy`.
  • A recuperação de notícias pode ser feita com parâmetros de consulta, e o texto da notícia em HTML pode ser renderizado para melhor leitura em ambientes como o Jupyter Notebook.

2.2 Modelagem de Tópicos (Latent Dirichlet Allocation - LDA)

  • A modelagem de tópicos é a aplicação de um modelo estatístico de linguagem que visa entender a estrutura que pode existir por trás de um texto, reduzindo os textos analisados, aplicando aprendizado de máquina não supervisionado para gerar tópicos (clusters de palavras), e classificando documentos de acordo com esses tópicos.
  • Modelos para modelagem de tópicos incluem Latent Semantic Analysis (LSA/LSI), Probabilistic Latent Semantic Analysis (pLSA) e Non-Negative Matrix Factorization (NNMF).
  • O LDA é um modelo estatístico que se baseia na crença de que cada tópico é uma mistura de um conjunto de palavras e que cada documento é uma mistura de um conjunto de tópicos.
  • Parâmetros principais do modelo LDA:
    • `α (alpha)`: Indica de quantos tópicos os documentos são compostos; quanto maior, mais específica a distribuição de tópicos por documento.
    • `β (eta)`: Indica de quantas palavras os tópicos são compostos; quanto maior, mais específica a distribuição de palavras por tópico.
  • No Python, o cálculo do modelo LDA pode ser realizado através da biblioteca **Gensim**. A biblioteca **scikit-learn** também permite a aplicação do modelo.
  • O processo de redução de texto para LDA envolve a obtenção de tokens (palavras) após a remoção de stop words.
  • Métricas de coerência são usadas para avaliar a qualidade dos tópicos gerados. É importante notar que, mesmo com o melhor valor de coerência, não há garantia de tópicos perfeitamente coerentes, pois é um modelo não supervisionado.
  • A visualização dos tópicos em clusters pode ser feita com `pyLDAvis.gensim.prepare` ou utilizando **t-SNE** (t-Distributed Stochastic Neighbor Embedding).
  • É possível criar nuvens de palavras (wordclouds) para visualizar as palavras-chave e sua contribuição percentual para cada tópico.

2.3 Modelos e Aplicações de Machine Learning

  • Redes Neurais Convolucionais (CNNs): Fazem a suposição chave de que os dados têm uma topologia de grade e que a estrutura local é importante, como em dados de imagem (pixels formando uma grade bidimensional, possivelmente com vários canais para componentes de sinal de cor). Valores de pixels próximos são mais relevantes para detectar características como bordas e cantos do que pontos de dados distantes. Aplicações iniciais focaram em dados de imagem, como reconhecimento de caligrafia.
  • Redes Neurais Feedforward Totalmente Conectadas: Não fazem suposições sobre a estrutura local dos dados de entrada, de modo que a reordenação arbitrária das características não tem impacto no resultado do treinamento.
  • Detecção de veículos a partir de imagens de satélite: Um caso particular de detecção de objetos. Utiliza um modelo chamado "100 layers Tiramisu" (uma extensão da arquitetura DenseNet), que é econômico em parâmetros (cerca de 9 milhões) comparado a redes anteriores como VGG19. O objetivo é explorar a reutilização de características e evitar a explosão de características. Um dataset de treinamento com 87.000 veículos anotados foi criado usando uma ferramenta de rotulagem interativa.
  • Técnicas de Conjunto de Árvores (Tree Ensembles): Incluem a construção de uma árvore de decisão individual (como CART), bootstrap aggregation (Bagging), métodos de boosting (como Adaptive Boosting, Gradient Boosting e Multiple Additive Regression Trees - MART) e Random Forest.
  • Máquinas de Vetor de Suporte (SVM) e suas variantes, como Support Vector Regression (SVR) e Least Squares Support Vector Regression (LSSVR), são usadas para diversas tarefas. Métricas como MSFE, QLIKE, MAFE, SDFE e Pseudo R2 são usadas para avaliar seu desempenho.
  • Modelos de Risco de Crédito: Modelos de Random Survival Forests podem ser usados para medição de risco de crédito de pequenas e médias empresas (PMEs).
  • Análise de Componentes Independentes (ICA): É um algoritmo para descobrir componentes latentes.
  • **Previsão de Ativos Extremamente Voláteis**: A aplicabilidade das ferramentas de ciência de dados para essa tarefa é um campo de estudo.

2.4 Análise de Redes

  • A análise de redes para economia e finanças tem aplicações como o estudo da propriedade de empresas.

2.5 Classificação e Limpeza de Dados

  • A classificação do setor de contrapartida em **dados EMIR** (European Market Infrastructure Regulation) é um desafio superado por algoritmos gulosos que usam múltiplas fontes de dados. Um algoritmo desse tipo classificou 96% do valor nocional de contratos em aberto no mercado de derivativos da área do euro.
  • Diebold–Mariano test: Usado para testar a hipótese nula de igual precisão de previsão entre dois métodos de previsão.

3. Análise Técnica do Mercado Financeiro

3.1 Filosofia e Lógica

  • A análise técnica é o estudo da ação do mercado (principalmente preço, volume e interesse aberto) por meio de gráficos, com o objetivo de prever tendências de preço futuras. O interesse aberto é usado apenas em mercados futuros e de opções.
  • As três premissas básicas da abordagem técnica são:
    1. O mercado desconta tudo: Tudo o que pode afetar os preços (fatores fundamentalistas, políticos, psicológicos, etc.) já está refletido neles. Consequentemente, basta estudar a ação do preço.
    2. Os preços se movimentam em tendências: Uma tendência em movimento tem maior probabilidade de continuar do que de reverter. Isso é uma adaptação da primeira lei de Newton (lei da inércia).
    3. A história se repete: Padrões gráficos identificados e categorizados ao longo do tempo refletem cenários de psicologia de alta ou baixa do mercado. Como funcionaram no passado, presume-se que continuarão a funcionar no futuro, pois a psicologia humana tende a não mudar.
  • Grafistas não se preocupam com os motivos dos preços subirem ou caírem; eles deixam o mercado lhes dizer o rumo provável.
  • A análise técnica pode ser aplicada universalmente a todos os mercados (ações, futuros, financeiros, taxas de juros, moedas estrangeiras, opções, hedging).
  • É flexível e adaptável a diferentes dimensões de tempo, desde day trading até previsões de longo alcance usando gráficos semanais e mensais de vários anos.
  • Diferenciação:
    • Grafista tradicional: Gráficos são a ferramenta principal, abordagem subjetiva. O sucesso depende da habilidade do grafista ("art charting").
    • Analista estatístico/quantitativo: Quantifica, testa e otimiza princípios subjetivos para desenvolver sistemas mecânicos de trading. Usa computadores para gerar sinais de compra e venda.

3.2 Críticas e Defesas da Análise Técnica

  • Profecia autorrealizável: A crítica de que muitos traders conhecem os padrões gráficos e agem da mesma forma, fazendo com que o padrão se realize. Contudo, a subjetividade dos padrões gráficos ("na mente de quem os vê") contradiz essa crítica, pois dificulta que todos vejam a mesma coisa ao mesmo tempo. A profecia autorrealizável pode ser vista como um elogio, indicando a influência da técnica.
  • O passado pode ser usado para prever o futuro? Críticos questionam a utilidade de dados de preços passados. Em defesa, todos os métodos de previsão (do tempo, fundamentalista) baseiam-se no estudo de dados passados. A análise gráfica é uma forma de análise de séries temporais.
  • Hipótese do Passeio Aleatório (Random Walk): Questiona se os preços realmente seguem uma tendência. A comunidade técnica rejeita essa ideia, afirmando que se os mercados fossem aleatórios, nenhuma técnica de previsão funcionaria. A hipótese do mercado eficiente é próxima da premissa técnica de que os mercados descontam tudo, mas acadêmicos pensam que não há como aproveitar essas afirmações rapidamente.
  • A análise técnica, por vezes, é reinterpretada por acadêmicos sob o nome de Finanças Comportamentais, que reconhecem a interligação entre psicologia humana e preços de títulos.
  • Relatórios do Federal Reserve Bank de Nova York (agosto de 1995) e do Federal Reserve Bank de St. Louis (outono de 1997) confirmaram que a análise técnica gera lucros estatisticamente significativos, mesmo desafiando o conceito de "mercados eficientes" e a hipótese simples do mercado eficiente.

3.3 A Teoria de Dow

  • Desenvolvida por Charles Dow, um dos fundadores do Dow Jones Financial News Service, que divulgou seus princípios em editoriais e nunca publicou uma obra formal.
  • É a **base fundamental** para qualquer estudo de análise técnica, com muitos conceitos modernos derivados dela.
  • **Princípios Básicos**:
    1. As Médias Descontam Tudo: Os preços de mercado refletem toda a informação disponível, incluindo fatores econômicos, descartando a necessidade de compilações elaboradas de índices adicionais.
    2. O Mercado Possui Três Tendências:
      • Tendência Primária: De grande duração (mais de um ano), com movimentos extensivos (podendo variar mais de 20%) e comparável à "maré". Tendência de alta primária apresenta topos e fundos ascendentes; tendência de baixa, topos e fundos descendentes.
      • Tendência Secundária (ou intermediária): As "ondas" que formam a maré.
      • Tendência Terciária: As "ondulações" que seguem as ondas.
    3. As Tendências Primárias Têm Três Fases: Acumulação, participação pública e distribuição.
    4. Os Índices Devem Se Confirmar: Um sinal de compra é dado quando as médias Dow Industrial e Dow Transportation fecham acima da alta anterior. Um sinal de venda ocorre quando ambas fecham abaixo da baixa anterior.
    5. O Volume Deve Confirmar a Tendência: O volume deve se expandir na direção da tendência primária.
    6. Uma Tendência Permanece em Vigor Até que um Sinal Definitivo de Reversão Seja Dado.
  • Dow confiava exclusivamente nos **preços de fechamento**, não considerando penetrações intraday válidas.

3.4 Construção de Gráficos

3.4.1 Gráficos de Barras

  • O **gráfico de barras diário** é o tipo mais usado na análise técnica.
  • Mostra os preços de abertura, mínimos, máximos e de fechamento para cada dia.
    • O **eixo vertical (y)** mostra a escala de preço, e o **eixo horizontal (x)** registra a passagem do tempo.
    • O **preço de fechamento** é marcado por um pequeno "tic" à direita da barra vertical; o de abertura, à esquerda.
  • As barras na parte inferior do gráfico medem o **volume**, que representa a atividade total de trading nesse mercado naquele dia.
  • O **interesse aberto** (total de contratos futuros em circulação nas mãos dos participantes do mercado no fim do dia) é marcado com uma linha sólida na parte inferior do gráfico, geralmente logo acima do volume.
  • **Gráficos semanais e mensais** comprimem a ação de preços, permitindo uma análise de tendência de maior alcance (semanais até cinco anos, mensais até vinte anos).

3.4.2 Candlesticks Japoneses

  • Versão japonesa dos gráficos de barras, que se tornou popular no ocidente. Munehisa Honma (1724-1803) é considerado o pai dos gráficos de candlestick, negociando arroz no mercado de Dojima, em Osaka, no século XVIII.
  • Registram os mesmos quatro preços (abertura, fechamento, máximo, mínimo), mas com uma apresentação visual diferente.
  • O **corpo real** mede a distância entre a abertura e o fechamento. É branco/aberto (ou verde, no ocidente) se o fechamento for maior que a abertura, e preto/preenchido (ou vermelho) se o fechamento for menor.
  • As linhas finas acima e abaixo do corpo são chamadas de **sombras** (ou pavios/cabelos) e mostram a variação de preço do dia (do máximo ao mínimo).
  • A relação entre abertura e fechamento é essencial nos candlesticks japoneses.
  • Os padrões de candlestick são mais úteis para identificar o início ou o final de movimentos de impulsão ou correção.
  • Padrões de reversão de Candlestick incluem:
    • Harami ("mulher grávida"): Corpo pequeno dentro do corpo anterior. Pouco confiável.
    • Martelo (Hammer): Corpo pequeno, pouca sombra superior, sombra inferior longa (mínimo 2x corpo). Confiabilidade média.
    • Estrela Cadente: Corpo pequeno, pouca sombra inferior, sombra superior longa (mínimo 2x corpo). Baixa confiabilidade.
    • Engolfo de Alta/Baixa: O segundo candle encobre totalmente o corpo do primeiro. Simples e de alta confiabilidade.
    • Pombo-Correio / Alinhamento na Baixa/Alta: Dois candles com corpos longos e fechamentos coincidentes. Baixa confiabilidade.
  • **Padrões de Continuação** de candlestick também existem, como os "Três Métodos de Alta" e "Três Métodos de Baixa".
  • **CandlePower** (ou **Candlevolume**): Combinação de gráficos de candlestick com o método gráfico Equivolume de Arms, onde a largura do candlestick é determinada pelo volume.
  • No Python, a biblioteca **Plotly** oferece simplicidade para a construção de gráficos de candlestick.

3.4.3 Gráficos de Ponto e Figura (P&F)

  • O **gráfico de ponto e figura** é o estudo do puro movimento de preço, sem levar o tempo em consideração.
  • Utiliza colunas alternadas de "x" (preços em alta) e "o" (preços em queda).
  • Os sinais de compra e venda são considerados mais precisos do que nos gráficos de barras.
  • Oferece flexibilidade: pode-se variar o critério de reversão (ex: de 3 para 5 boxes) e o tamanho do box para ajustar a sensibilidade do gráfico a diferentes propósitos de análise (curto, intermediário, longo prazo).
  • A **contagem horizontal** é uma das principais vantagens, permitindo obter objetivos de preço. Baseia-se na premissa de que há uma relação direta entre a largura de uma área de congestão e o movimento subsequente após um breakout.
  • **Padrões de preço** em P&F são semelhantes aos de gráficos de barras (topos/fundos duplos/triplos, cabeça e ombros, V's, pires). O termo "fulcro" refere-se a uma área de congestão bem definida que forma uma base de acumulação ou um topo de distribuição.
  • **Gráficos de P&F com três reversões** (método Chartcraft): A construção exige apenas os preços máximos e mínimos do dia. Linhas de tendência são traçadas em ângulos de 45°.
  • **Técnicas de mensuração** para gráficos de reversão de três pontos:
    • **Horizontal**: Conta o número de colunas nos padrões de fundo ou topo, multiplica pelo valor de reversão (ex: 3) e soma/subtrai do fundo/topo para o objetivo de preço.
    • **Vertical**: Mede o número de boxes na primeira coluna da nova tendência, multiplica por três e soma/subtrai do fundo/topo da coluna.
  • **Táticas de trading** incluem o uso de sinais de compra/venda, linhas de tendência como filtro, e pontos de stop protetivos. Permite o uso de "stop de rastreamento" para proteger lucros acumulados.
  • **Vantagens**: Sinais de trade mais precisos e facilitação da disciplina.
  • **Indicadores Técnicos de P&F**: Podem ser aplicados à análise de força relativa, setor e à construção de índices como o NYSE Bullish Percent Index.
  • **Gráficos de P&F por computador**: Facilitam a construção, permitem variar o tamanho dos boxes e reversões, e podem aplicar **médias móveis de P&F** (calculando a média de preço de cada coluna).
  • **Gráficos logarítmicos de P&F**: Utilizam critérios de reversão baseados em porcentagens.

3.4.4 Escalas de Preço

  • **Escala aritmética**: Leva em conta a variação nominal dos preços, com espaçamento igual na escala vertical.
  • **Escala logarítmica**: Considera a variação percentual dos preços, tornando os gráficos mais harmônicos e adequados para análise, especialmente em períodos mais longos. Recomenda-se para traçar linhas de canal em tendências de longo prazo.

3.5 Conceitos Básicos de Tendência

  • Uma tendência tem **três direções** (alta, baixa, lateral) e **três classificações** (primária, secundária, de curto prazo).
  • A **tendência de curto prazo** é usada principalmente para timing, enquanto a **tendência intermediária** (que pode durar vários meses) é o foco da maioria das abordagens seguidoras de tendências.

3.5.1 Suporte e Resistência

  • **Suporte**: Uma baixa anterior que atua como barreira abaixo do mercado, detendo a queda dos preços.
  • **Resistência**: Um pico de preços anterior que atua como barreira acima do mercado, detendo o avanço dos preços.
  • Quando um pico de resistência é testado, a tendência de alta está em uma fase crítica. Não exceder um pico anterior em uma tendência de alta, ou a capacidade dos preços se afastarem da baixa de suporte anterior, são os primeiros avisos de que a tendência está mudando.
  • **Inversão de papéis**: Sempre que um nível de suporte ou resistência é penetrado por uma quantidade significativa, eles invertem seus papéis (a resistência se torna suporte e vice-versa). Antigos picos de resistência podem se tornar novos níveis de suporte, e antigos suportes podem se tornar resistência.
  • **Números redondos** e, especialmente, números redondos importantes, são frequentemente respeitados pelos mercados como níveis de suporte e resistência.
  • O **Pivot** é a média aritmética do preço de fechamento, máxima e mínima do dia. A partir dele, podem-se calcular resistências (R1, R2, R3) e suportes (S1, S2, S3) com fórmulas específicas.

3.5.2 Linhas de Tendência

  • Uma **linha de tendência de alta** é uma linha reta desenhada para cima e para a direita ao longo de reações de baixa sucessivas (baixos ascendentes). Requer pelo menos dois pontos, e uma terceira baixa confirma sua validade.
  • Uma **linha de tendência descendente** é traçada para baixo e para a direita ao longo de picos de alta sucessivos (altos descendentes).
  • A **importância de uma linha de tendência** é determinada pelo tempo em que permaneceu intacta e pelo número de vezes que foi testada com sucesso.
  • As linhas de tendência em gráficos de barras devem incluir **toda a variação de preço do dia**, não apenas os preços de fechamento.
  • Uma **quebra válida** de uma linha de tendência geralmente é um fechamento além da linha. Podem ser usados filtros de tempo e preço, como o critério de penetração de 3% (excluindo alguns futuros financeiros).
  • As **linhas de tendência também invertem os papéis**: Uma linha de tendência de alta (suporte) torna-se uma linha de resistência quando decisivamente quebrada para baixo, e vice-versa.
  • **Implicações de mensuração**: Quando uma linha de tendência é quebrada, os preços geralmente avançam uma distância além da linha igual à distância vertical alcançada pelos preços no outro lado da linha, antes da inversão.
  • A **inclinação relativa da linha de tendência** é importante. Linhas muito planas podem precisar ser redesenhadas em ângulos mais inclinados se a tendência acelerar.
  • A **linha do canal** é uma linha paralela à linha de tendência que serve como limite superior ou inferior para o movimento de preço.

3.5.3 Outros Conceitos

  • O **Princípio do Leque** utiliza três linhas.
  • A **Importância do Número Três**: O número três aparece frequentemente na análise técnica (ex: três linhas de leque, três fases de mercado, três tipos de gaps, padrões de reversão com três picos, três classificações/direções de tendência, três tipos de triângulos, três fontes de informação: preço, volume e interesse aberto).
  • **Porcentagens de Retração**:
    • Após um movimento de mercado, os preços retraçam uma porção da tendência anterior antes de retomar o movimento na direção original. Esses movimentos contrários à tendência frequentemente se encaixam em parâmetros percentuais previsíveis.
    • A **retração de 50%** é a aplicação mais conhecida do fenômeno.
    • Parâmetros mínimos e máximos reconhecidos são as retrações de **1/3 (33%)** e **2/3 (66%)**. Se os preços se moverem além do ponto de 2/3, é provável que haja uma reversão de tendência, não apenas uma retração.
    • As retrações de **Fibonacci (38% e 62%)** são populares entre os grafistas.
    • Os oitavos de W. D. Gann (1/8 a 8/8) também dão importância especial a 3/8 (38%), 4/8 (50%) e 5/8 (62%).
  • **Speedlines**: Linhas usadas em conjunto com retrações.
  • **Linha de Gann e Leque de Fibonacci**.
  • **Linhas de Tendência Internas**: Traçadas através da ação dos preços, conectando o máximo de máximos e mínimos possível.
  • **Dias de Reversão**: Formações de gráfico (alta/baixa, clímax de compra/venda, dia de reversão-chave) que podem ser significativas no contexto de outras informações técnicas.
  • **Gaps de Preço**: Existem três tipos de gaps.
    • A **Ilha de Reversão** é um padrão formado por um gap de exaustão de alta seguido por negociação limitada e depois um gap de baixa, sinalizando uma reversão de tendência significativa.

3.6 Padrões de Preço

  • São quadros ou formações que aparecem nos gráficos de preços de ações ou commodities, classificáveis e com valor preditivo.
  • Existem duas categorias principais: Reversão e Continuação.
  • O **volume** desempenha um papel importante de confirmação em todos os padrões de preço. Em momentos de dúvida, o padrão de volume pode ser decisivo para a confiabilidade.
  • A maioria dos padrões de preço possui **técnicas de mensuração** para determinar objetivos de preço mínimo. Estes objetivos são aproximações úteis para avaliar a relação risco/retorno.
  • A existência de uma **tendência anterior relevante** é um pré-requisito para qualquer padrão de reversão.
  • **Padrões de fundo** normalmente têm variações de preço menores e levam mais tempo para se formar. O volume é geralmente mais importante na alta.

3.6.1 Padrões de Reversão Importantes

  • Indicam que uma reversão importante em uma tendência está ocorrendo. Geralmente levam mais tempo para se formar e representam mudanças de tendência significativas.
  • **Cabeça e Ombros**: Provavelmente o padrão de reversão mais conhecido e confiável.
    • Formação de topo: Apresenta um ombro esquerdo (ponto A, volume alto), uma cabeça (ponto C, nova alta, volume menor que em A), e um ombro direito (ponto E, volume leve, não atinge o topo da cabeça). A queda após a cabeça (D) rompe o pico anterior (A). Um fechamento abaixo da **linha do pescoço** (que conecta as baixas B e D) completa o padrão. Um movimento de retorno à linha do pescoço é comum.
    • **Cabeça e Ombros Invertido (Fundo)**: Uma imagem espelhada do padrão de topo. O volume maior é um ingrediente essencial para finalizar o padrão de base. O movimento de retorno à linha do pescoço é mais comum nos fundos e deve ocorrer com volume pequeno.
    • **Linha do Pescoço**: Pode inclinar-se ligeiramente para cima (em topos) ou para baixo (em fundos). A inclinação descendente em topos é um sinal de fraqueza.
    • **Técnica de Mensuração**: A distância vertical da cabeça até a linha do pescoço é projetada para baixo a partir do ponto de rompimento da linha do pescoço, fornecendo um objetivo de preço mínimo.
    • Pode, ocasionalmente, agir como padrão de consolidação.
  • **Topos e Fundos Triplos**: Uma variação mais rara do cabeça e ombros, onde os três picos ou vales ficam mais ou menos no mesmo nível. O volume em cada pico de rali deve ser menor, e o padrão se completa quando ambos os vales são rompidos com volume maior. Para fundos, o volume é mais importante no breakout ascendente. A técnica de mensuração é semelhante ao cabeça e ombros, baseada na altura do padrão.
  • **Topos e Fundos Duplos**: Um padrão de reversão mais comum e facilmente reconhecido depois do cabeça e ombros.
    • **Topo Duplo ("M")**: Dois picos proeminentes praticamente no mesmo nível de preço. O volume tende a ser maior no primeiro pico e menor no segundo. Completa-se com um fechamento decisivo abaixo do vale central com volume maior. Um movimento de retorno ao ponto de rompimento não é incomum.
    • **Fundo Duplo ("W")**: Imagem espelhada do topo duplo, com o volume mais importante no breakout ascendente. O fundo se completa quando o pico médio é excedido.
    • **Técnica de Mensuração**: A altura do padrão é projetada a partir do ponto de breakdown.
    • O **tempo entre picos ou vales** é importante; topos/fundos duplos válidos devem ter pelo menos um mês entre eles, podendo abranger vários anos em gráficos de longo alcance.
  • **Pires (Rounded Bottoms)**: Mostra uma virada gradual e muito lenta de uma tendência de baixa para lateral e para cima. Geralmente são identificados em gráficos semanais ou mensais que abrangem vários anos. Quanto maior sua duração, mais significativos se tornam.
  • **Spikes (Topos/Fundos em V)**: Reversões repentinas que ocorrem com pouco ou nenhum aviso. Uma queda repentina de preço com volume alto é geralmente a única indicação. Difícil de identificar com antecedência.
  • **Fundos em W**: Consequência do trabalho de Arthur Merril, identificados com Bandas de Bollinger. Envolve uma nova baixa abaixo da banda inferior, um rebate para a banda do meio, uma nova baixa acima da banda inferior, e confirmação com um rompimento da segunda baixa.

3.6.2 Padrões de Continuação

  • Indicam uma pausa na tendência predominante, após a qual a tendência original será retomada. Geralmente têm duração menor e são classificados como padrões de curto prazo ou intermediários.
  • **Triângulos**: Geralmente padrões de continuação, mas às vezes funcionam como padrões de reversão.
    • **Triângulo Simétrico (ou mola)**: Representa uma pausa em uma tendência existente, com linhas de tendência convergentes. Requer no mínimo quatro pontos de reversão (dois toques em cada linha).
    • **Limite de Tempo para Resolução**: Os preços devem se mover na direção da tendência anterior entre 2/3 e 3/4 da extensão do triângulo (da base vertical ao vértice).
    • **Volume**: Diminui visivelmente durante a formação do padrão, mas tende a aumentar nos bounces e diminuir nas quedas em uma tendência de alta. Um aumento de volume é essencial para a retomada de uma tendência de alta.
    • **Técnica de Mensuração**: A altura da linha vertical na parte mais larga do triângulo (base) é projetada a partir do ponto de breakout.
    • **Triângulo Ascendente**: Linha superior horizontal e linha inferior ascendente.
    • **Triângulo Descendente**: Linha inferior horizontal e linha superior descendente. Pode aparecer em topos de mercado, sinalizando uma reversão para baixo.
    • Os triângulos de Elliott se dividem em cinco ondas, cada uma com três ondas próprias, e são classificados em ascendentes, descendentes, simétricos e extensíveis.
  • **Formação de Alargamento (Triângulo Invertido ou Megafone)**: As linhas de tendência divergem, criando uma imagem de triângulo em expansão. É uma variação incomum e relativamente rara do triângulo.
  • **Bandeiras e Flâmulas**: Padrões de curto prazo que geralmente duram de uma a três semanas, podendo ocorrer no ponto médio de um movimento.
    • **Bandeira**: Parece um paralelogramo descendente (em tendência de alta) ou ascendente (em tendência de baixa).
    • **Flâmula**: Semelhante a um pequeno triângulo simétrico, mas mais horizontal.
    • O volume deve diminuir visivelmente durante a formação.
    • **Implicações de Mensuração**: São consideradas "hasteadas à meia-haste". O movimento após a retomada da tendência deve duplicar o "mastro" (avanço/declínio acentuado precedente).
  • **Formação em Cunha (Wedge)**: Padrão de continuação (ou reversão) com linhas de tendência convergentes, ambas ascendentes (cunha ascendente, de baixa) ou ambas descendentes (cunha descendente, de alta).
  • **Formação do Retângulo**: Pausa na tendência onde os preços se movem lateralmente entre duas linhas horizontais paralelas. Geralmente dura de um a três meses. O padrão de volume difere de outros padrões de continuação por não apresentar o habitual dropoff.
    • **Técnica de Mensuração**: A altura da faixa de preço é medida e projetada a partir do ponto de breakout.
  • **Movimentos Mensurados (Mensuração da Flutuação)**: Um avanço ou queda importante no mercado é dividido em dois movimentos iguais e paralelos. A segunda "perna" do avanço (CD) duplica o tamanho e a inclinação da primeira (AB).
  • **Padrão de Continuação de Cabeça e Ombros**: Pode, ocasionalmente, aparecer como um padrão de consolidação. Em uma tendência de alta, o vale central é mais baixo que os ombros; em uma tendência de baixa, o pico central excede os outros dois picos.

3.7 Volume e Interesse Aberto em Detalhe

  • A análise de **volume** se aplica a todos os mercados, e o **interesse aberto** aplica-se principalmente ao mercado de futuros.
  • O **volume** mede a intensidade ou urgência do movimento de preço. Volume maior reflete um grau mais alto de intensidade ou pressão. É usado para confirmar movimentos de preço ou avisar que um movimento não é confiável.
  • O **On Balance Volume (OBV)** é uma variação que rastreia o fluxo de volume. A linha OBV deve seguir na mesma direção da tendência de preço; se houver divergência, sinaliza uma possível reversão. Pode-se traçar suportes e resistências no gráfico do OBV para confirmar novas tendências.
  • As regras de interpretação de mudanças no **interesse aberto** são semelhantes às de volume.
  • O **Relatório de Compromisso dos Traders (COT)** publica as posições líquidas de três grupos de traders. É útil para localizar extremos e oportunidades de compra/venda.

3.8 Gráficos de Longo Prazo

  • Proporcionam uma perspectiva da tendência de mercado que seria impossível de atingir apenas com gráficos diários.
  • **Gráficos Contínuos para Mercados Futuros**: Necessários devido à vida limitada dos contratos de futuros. A técnica mais simples é ligar contratos usando o preço do contrato com vencimento mais próximo. Outros meios incluem ligar meses específicos (sugerido por W.D. Gann) ou usar médias de preços de vários contratos (Perpetual Contract™), que é uma média ponderada de dois outros preços para atenuar distorções e proporcionar continuidade.
  • A ordem correta para análise de tendências minuciosa é começar com o longo prazo e gradualmente passar ao curto prazo.
  • Gráficos semilogarítmicos são mais valiosos para o estudo de tendências de preços de longo prazo.

3.9 Médias Móveis

  • A **média móvel** é um dos indicadores técnicos mais versáteis e amplamente utilizados, formando a base de muitos sistemas mecânicos de seguimento de tendências.
  • É um **dispositivo suavizador** que introduz defasagem de tempo nos sinais.
  • O **preço de fechamento** é o mais comumente usado para o cálculo da média móvel.
  • **Tipos de Médias Móveis**:
    • **Média simples**: Confere peso igual aos preços de todos os dias no cálculo.
    • **Médias exponenciais**: Dão mais peso aos dados mais recentes.
  • **Combinações comuns**:
    • Em futuros diários: 4 e 9, 9 e 18, 5 e 20, 10 e 40.
    • Em ações: 50 dias (ou 10 semanas).
    • Para análise de longo prazo: 30 e 40 semanas (ou 200 dias).
  • **Envelopes de Médias Móveis**: Bandas plotadas acima e abaixo da média móvel por uma porcentagem fixa.
  • **Bandas de Bollinger**: Usam uma média móvel de 20 dias e dois desvios padrão acima e abaixo. Podem ser usadas como alvos e a largura da banda mede a volatilidade. Não se baseiam na suposição de distribuição normal dos preços.
  • As médias móveis são valiosas em **gráficos semanais**, fornecendo suporte durante correções em mercados de alta.
  • A **Regra Semanal** (ex: 4 semanas) é um sistema mecânico que gera sinais de compra e venda com base nas máximas e mínimas de um período.
  • Softwares gráficos permitem **otimizar** os parâmetros das médias móveis para se adequar a condições de mercado em mudança.
  • **HiLo Activator**: Um indicador baseado em médias móveis que sinaliza compra ou venda. Em mercados laterais, pode gerar vários sinais falsos. Um algoritmo simplificado pode ser implementado em Python para marcar a mínima do candle de virada e efetuar a venda ao romper essa mínima no candle seguinte.

3.10 Osciladores e Opinião Contrária

  • **Osciladores** são ferramentas que flutuam entre extremos, úteis para identificar condições de sobrecompra/sobrevenda e divergências, especialmente em mercados laterais.
  • **Medindo o Momentum**: Muitos osciladores medem o momentum, ou a taxa de variação dos preços.
  • **Taxa de Variação (ROC - Rate of Change)**: Mede a variação percentual de um preço ao longo de um período de tempo.
  • **Construindo um Oscilador Usando Duas Médias Móveis**: A diferença entre duas médias móveis pode ser plotada como um histograma, gerando sinais de compra e venda quando cruzam a linha zero.
  • **Índice de Força Relativa (IFR - Relative Strength Index)**: Um oscilador de momentum que flutua em uma faixa vertical entre 0 e 100. Leituras acima de 70-80 são sobrecompradas, e abaixo de 20-30 são sobrevendidas. A linha IFR é menos volátil e atinge extremos com menor frequência que o estocástico.
  • **Estocásticos (%K e %D)**: Medem o preço de fechamento em relação à faixa de preço total em um período de tempo selecionado. Flutuam entre 0 e 100. Leituras acima de 80 são sobrecompradas, abaixo de 20 são sobrevendidas. O **estocástico lento** (média móvel de três períodos da linha %D) é mais usado por apresentar sinais mais confiáveis. Sinais de compra e venda são dados pelos cruzamentos das linhas %K e %D.
  • **Larry Williams %R**: Baseia-se em conceito semelhante ao estocástico, medindo o fechamento em relação à faixa de preço.
  • **Convergência/Divergência de Média Móvel (MACD - Moving Average Convergence/Divergence)**: Desenvolvido por Gerald Appel, consiste em duas linhas:
    • A **Linha MACD**: Diferença entre duas médias móveis exponenciais (geralmente 12 e 26 períodos) de preços de fechamento.
    • A **Linha de Sinal**: Geralmente uma média móvel exponencial de nove períodos da Linha MACD.
    • Sinais de compra e venda são dados quando as duas linhas se cruzam.
  • **Histograma MACD**: Plota a diferença entre a Linha MACD e a Linha de Sinal, fornecendo uma visão mais aguçada sobre o equilíbrio de poder entre compradores e vendedores.
  • **O Princípio da Opinião Contrária**: Envolve operar na direção oposta à maioria quando os números de consenso atingem extremos. Funciona melhor quando a maior parte do interesse aberto está nas mãos de especuladores ("weaker hands").
  • **Leitura da Disposição do Investidor**: Mede o sentimento do mercado.
  • **Números da Investors Intelligence**: Referem-se a dados sobre a opinião dos investidores.
  • A **Análise de Direção Média (ADX - Average Directional Index)** mede a força da tendência. É útil para determinar se um mercado está em tendência (ADX acima de 20) ou lateral, ajudando a evitar sinais falsos de outros indicadores como o HiLo.
  • A **Tendência** pode ser sinalizada como Alta, Baixa ou Neutra a partir da análise combinada do IFR14 e do MACD.

4. Teoria das Ondas de Elliott

  • Desenvolvida por R. N. Elliott, baseia-se na **sequência de números de Fibonacci** como sua estrutura matemática fundamental.
  • A teoria das ondas consiste em três aspectos: **forma da onda, razão e tempo**.
  • Um ciclo completo consiste em **oito ondas** (cinco ascendentes e três descendentes), todos números de Fibonacci. Subdivisões maiores também resultam em números de Fibonacci (34, 144 ondas).
  • A divisão de uma onda em cinco ou três sub-ondas é determinada pela direção da próxima onda maior. Ondas que se movem a favor da tendência maior se subdividem em cinco, enquanto as que se movem contra se subdividem em três.
  • A **regra da alternância** defende que o mercado geralmente não age da mesma forma duas vezes seguidas, e padrões de correção tendem a se alternar (ex: se a onda de correção 2 foi simples, a onda 4 será complexa).
  • **Canais de preço** são usados como método para alcançar objetivos de preço e confirmar a finalização da contagem de ondas. Recomenda-se o uso de gráficos semilogarítmicos para traçar linhas de canal em tendências de longo prazo.
  • A **onda 4** funciona como uma área de suporte em mercados de baixa subsequentes; o mercado de baixa geralmente não se moverá abaixo da quarta onda anterior do grau menor.
  • **Razões e Retrações de Fibonacci**:
    • As razões de Fibonacci (ex: 1,618 ou seu inverso 0,618 para números adjacentes; 2,618 ou 0,382 para números alternados) ajudam a determinar objetivos de preço em ondas de impulso e correção.
    • Os números mais comumente usados para retrações de porcentagem são 61,8% (arredondado para 62%), 38% e 50%. Em uma tendência forte, a retração mínima é de 38%; em uma mais fraca, a máxima é de 62%.
    • Alvos de tempo de Fibonacci também podem ser aplicados, mas sua relevância nem sempre é clara antes do fato.
  • A teoria foi concebida para ser aplicada às **médias do mercado de ações**, e não tão bem a ações individuais ou a alguns mercados de futuros. Funciona bem em veículos de ampla cobertura como o ouro.

5. Ciclos de Tempo

  • Os **ciclos** são conceitos que ajudam a explicar técnicas de representação gráfica.
  • As três características principais dos ciclos são: **Cristas** (topos), **Vales** (fundos) e **Duração**. Analistas preferem medir a duração dos ciclos de vale a vale, pois são mais estáveis e confiáveis.
  • **Princípios Cíclicos**:
    • **Somatória**: Todos os movimentos de preço consistem na simples adição de todos os ciclos ativos. Defende que todos os padrões de preço são formados pela interação de dois ou mais ciclos diferentes.
    • **Harmonia**: Ondas vizinhas geralmente estão ligadas por um número inteiro baixo (normalmente 2), ou seja, o próximo ciclo mais curto/longo tem metade/o dobro da duração.
    • **Sincronia**: Todos os ciclos atingem seus vales na mesma data, ou vales de ciclos de duração mais curta atingem suas baixas antes.
    • **Proporção**: A relação entre vales adjacentes é de um número inteiro baixo.
    • **Nominalidade**: Existe um conjunto nominal de ciclos harmonicamente relacionados que afetam todos os mercados, servindo como ponto de partida na análise.
  • Conceitos cíclicos ajudam a explicar técnicas como linhas de tendência e canais, padrões de gráficos e médias móveis.
  • A **Transposição (Translation) para a Esquerda e a Direita** descreve como a tendência do ciclo maior afeta a posição do pico médio em ciclos mais curtos.
  • **Isolando ciclos**: A inspeção visual de gráficos de barras diários pode ajudar a identificar topos e fundos óbvios. Ferramentas como o **Ehrlich Cycle Finder** ou o **Ehrlich Cycle Forecaster** (disponível na Omega Research) auxiliam na identificação de ciclos.
  • **Ciclos Sazonais**: Padrões de preço que se repetem ao longo do ano. Exemplos incluem queda do cobre em outubro/fevereiro, pico em abril/maio; pico do petróleo em outubro e virada em março; queda do dólar em janeiro; altas de títulos do Tesouro dos EUA em janeiro.
  • **Ciclos no Mercado de Ações**: Incluem o Barômetro de Janeiro e o Ciclo Presidencial.
  • **Análise Espectral de Entropia Máxima**: Técnica para análise de ciclos.

6. Computadores e Sistemas de Trading

6.1 Ferramentas e Requisitos

  • O computador é uma ferramenta valiosa para traders tecnicamente orientados, melhorando a análise e permitindo o teste e otimização de sistemas e indicadores.
  • **Software Gráfico**: Oferece diversas rotinas técnicas e a capacidade de automatizar funções, testar a lucratividade de estudos e gerar sinais de compra e venda.
  • A maioria dos softwares gráficos é **user-friendly** e compatível com IBM.
  • Os pacotes gráficos não fornecem dados diários de mercado; o usuário deve obtê-los de serviços de dados, que podem ser coletados automaticamente (com modem) ou de fornecedores que oferecem dados históricos em CD-Rom ou capacidade gráfica (como Telescan).
  • **EasyLanguage**: Linguagem de programação relativamente simples usada na plataforma TradeStation da Omega Research para desenvolver, testar e otimizar sistemas de trading.
  • É possível usar o computador para desenvolver **redes neurais** mais sofisticadas.
  • No mundo real, as estratégias de negociação exigem **dados em tempo real**, que são obtidos através de APIs ou serviços de terceiros.
  • Os scripts precisam ser **componentizados e otimizados** para minimizar o uso de processamento e memória, além de serem tolerantes a falhas. Devem ser executados em ambientes com alta tolerância a falhas, como a nuvem.

6.2 Sistemas de Trading

  • **Sistemas de trading mecânicos** são baseados em regras objetivas, o que minimiza ou elimina o elemento subjetivo humano na operação, conferindo-lhe um caráter mais científico e aumentando as chances de repetir o desempenho passado.
  • As três principais categorias de sistemas de trading são:
    • Seguidores de tendências: Operam na direção da tendência principal, comprando de acordo com a alta e vendendo de acordo com a baixa. Médias móveis e a regra semanal de Donchian são metodologias populares.
    • Contratendência: Operam contra a tendência principal, adicionando correlação negativa e resultando em curvas de equity mais suaves quando combinados com sistemas seguidores de tendências.
    • Reconhecimento de padrões: Pode ser visual (como o cabeça e ombros) ou estatístico (como padrões sazonais).
  • Os sistemas podem ser usados como **confirmação mecânica** ou como um **dispositivo de disciplina** para manter o trader no lado certo da tendência principal. Também podem servir como **alertas** para mudanças de tendências recentes.
  • **Operar vendido ("Short Selling")**: Abrir uma posição vendendo um ativo sem tê-lo, e fechar a posição comprando-o.

6.3 Plano de Cinco Etapas para Construir um Sistema de Trading

  • Desenvolvido para criar um conceito saudável que se desempenhe razoavelmente bem no passado e possa continuar a fazê-lo no futuro.
    1. Comece com um conceito (uma ideia): Desenvolva suas próprias ideias observando gráficos, identificando cruzamentos de médias móveis, osciladores, configurações de padrões de preço ou outros indícios objetivos que precedem movimentos de mercado importantes. Estudar sistemas de trading de outras pessoas também é recomendado.
    2. Transforme-o em um conjunto de regras objetivas: Manifeste a ideia em termos objetivos, de modo que qualquer pessoa que siga as regras chegue exatamente às mesmas conclusões. Isso exige dividir o problema em detalhes programáveis.
    3. Verifique-o visualmente nos gráficos: Após definir as regras, faça uma verificação visual informal dos sinais de trading no gráfico de preços para garantir que a ideia foi expressa adequadamente e que é potencialmente lucrativa antes de programar.
    4. Teste-o formalmente com o computador: Converta a lógica em código (ex: EasyLanguage da TradeStation) e teste em diferentes períodos de tempo e vários mercados. Evite otimizar o mínimo possível para dados históricos para não criar expectativas irreais de retornos.
    5. Avalie os resultados: Inspecione visualmente os sinais gerados pelo computador e faça as correções necessárias no código se o sistema não fizer o que se propõe.
  • **Gerenciamento de dinheiro** e **diversificação** são aspectos cruciais do sucesso do trading.

7. Gestão de Risco de Modelos (MRM)

  • A **Supervisory Guidance on Model Risk Management (SR 11-7)**, emitida pelo Federal Reserve e Office of the Comptroller of the Currency (OCC), fornece diretrizes para a gestão de risco de modelos.
  • O **ciclo de vida do modelo** é um conceito chave na MRM.
  • O **Fundamental Review of the Trading Book (FRTB)** é uma estrutura regulatória para gestão de risco de mercado.
  • **Backtesting**: Técnica para testar a validade de modelos de risco, como o **Value at Risk (VaR)**.
    • O teste de cobertura de Kupiec (Kupiec Pof-Test) é um método para backtesting de VaR.
    • Sistemas de backtesting em Python podem ser construídos usando bibliotecas como `backtesting.py`. No entanto, um backtesting simples pode não considerar fatores como drawdown, stop-loss ou aluguel de ações.
  • **Análise de Sensibilidade**: Técnica que avalia como as saídas de um modelo são afetadas por mudanças em suas entradas. Usada para avaliar a robustez e identificar áreas de vulnerabilidade do modelo.
  • **Viés Algorítmico**: Uma preocupação crescente em serviços financeiros, especialmente em decisões de crédito e seguros. Ferramentas como `fairlens` e `FAT Forensics` (Python Toolbox) são usadas para identificar viés e medir a equidade de dados e modelos de ML. A biblioteca `audit-ai` detecta diferenças demográficas na saída de modelos de ML.
  • **Inteligência Artificial Explicável (XAI)**: Essencial para compreender como os modelos de IA tomam decisões, o que é fundamental para a avaliação e mitigação de riscos financeiros.
    • **Gradientes Integrados**: Um método popular de XAI que produz atribuições para cada pixel em uma imagem, baseando-se em uma linha de base (ex: imagem preta sólida, frase vazia) e transformando-a gradualmente na entrada real.
    • Outros métodos de atribuição visual incluem Ablação, Oclusão, Shapley e KernelSHAP. Eles podem indicar que o modelo aprendeu a focar em características como texto ou contatos em imagens de baterias, ou bordas quebradas em vidro.
    • A **decomposição de efeitos elementares** pode ser usada para visualizar a importância dos fatores.

11. Modelos de Markov e Séries Temporais

  • Uma **cadeia de Markov** é um processo estocástico onde a probabilidade de transição para o próximo estado depende apenas do estado atual, e não da sequência de eventos anteriores. Variáveis aleatórias podem ser independentes ou identicamente distribuídas.
  • **Modelos Ocultos de Markov (HMMs - Hidden Markov Models)** são modelos para séries temporais onde os estados internos não são diretamente observáveis (ocultos). Podem ser visualizados como um diagrama de transição de estados desdobrado ao longo do tempo, formando uma estrutura de treliça onde cada coluna corresponde a uma variável latente.
  • A **matriz de transição P** define as probabilidades de transição entre os estados.
  • **Distribuições estacionárias**: Quando todas as linhas da matriz de transição se tornam aproximadamente iguais (para n tendendo ao infinito), o processo se torna independente da distribuição de probabilidade inicial.
  • O **vetor de probabilidade de estado estacionário (π)** é encontrado resolvendo-se um problema de autovalor (Pπ = π), onde o autovalor é igual a 1. O autovetor correspondente é normalizado para que sua soma seja 1.
  • Os **HMMs** podem ser formulados e estimados para dados univariados (contagens ilimitadas/limitadas, binários, contínuos, proporções, circulares) e multinomiais/categóricos.
  • **Pseudorresíduos** são usados para avaliar a adequação de modelos ajustados, baseados na distribuição condicional de uma observação em relação a todas as outras.
  • O **Tempo de Primeira Passagem** é o tempo necessário para o processo atingir um estado `j` a partir de um estado `i`. Se `j = i`, é o **Tempo de Recorrência**.

12. Reconhecimento de Padrões e Machine Learning

  • **Análise de Componentes Principais (PCA - Principal Component Analysis)**: É uma técnica para encontrar representações de baixa dimensão que retêm o máximo de informação possível, minimizando a perda de compressão. Pode ser vista como um gargalo que controla o fluxo de informação entre os dados originais e sua projeção, atuando como um par de operações de codificadores e decodificadores.
  • **PCA Probabilístico**: Permite a visualização das projeções médias dos pontos de dados no subespaço principal.
  • **Kernel PCA**: Envolve encontrar os autovetores de uma matriz N x N (K) em vez da matriz D x D (S) da PCA linear convencional.
  • **Modelos de Constelação (Weakly Supervised)**: São usados para reconhecimento de objetos, aprendendo os parâmetros do modelo a partir de imagens de treinamento que contêm o objeto de interesse e "background clutter".
  • **Rótulos de Baixo Custo (Loose Labels)**: Textos que naturalmente acompanham as imagens podem servir como rótulos baratos, embora ruidosos. Exemplos incluem imagens com legendas em páginas da web, fotos de notícias, coleções de fotos de estoque ou diálogos de filmes.
  • **Modelos de Espaço Latente**: Podem ser usados para autoanotação de imagens e para modelar a distribuição conjunta de palavras e regiões ou cenas.
  • **Aprendizagem Ativa (Active Learning)**: Estratégias que selecionam os exemplos mais informativos para anotação manual, minimizando os custos de rotulagem. Isso pode incluir a anotação de imagens, com rótulos múltiplos e múltiplas perguntas, seleção não míope e em lote, e classificação ativa.
  • **Classificação Imbalanceada**:
    • Métodos clássicos para balancear datasets incluem OSS (One-Sided Selection) e Tomek Links, que removem exemplos próximos a exemplos de minorias ou partes internas de quadrados. O OSS usa Tomek Links e um processo de condensação por CNN.
    • Outras técnicas incluem ADASYN (adaptive synthetic sampling approach), over-sampling baseado em grafo, e aprendizado semissupervisionado sintético.
    • Combinações de técnicas de oversampling e undersampling (ex: SMOTEENN) podem ser aplicadas.
    • Weighted Support Vector Machines (SVMs): O algoritmo SVM pode ser modificado para ponderar a penalidade de margem proporcionalmente à importância da classe durante o treinamento, sendo útil para classificação imbalanceada.

14. Gestão de Portfólio

  • O **Modelo Black-Litterman** é um modelo de alocação de ativos que combina visões de mercado com visões de investidores.
  • O **Value at Risk (VaR)** e o **Expected Shortfall (ES)** são medidas de risco amplamente utilizadas em finanças para estimar o risco de cauda.
  • A **otimização Bayesiana de Portfólio** utiliza o modelo Black-Litterman e medidas de risco como VaR e CVaR (Conditional Value at Risk). A inferência bayesiana oferece estratégias para a gestão de risco e previsão de risco.
  • A **diversificação** é uma estratégia conhecida para redução de riscos em investimentos, embora haja controvérsias (ex: Max Gunther no livro "Os Axiomas de Zurique").
  • A **otimização de portfólio de Markowitz** é um método para otimização de carteiras.
  • O **Sharpe Ratio** é uma métrica para calcular o retorno ajustado ao risco.

15. Tópicos Adicionais

  • O **Perpetual Contract™** é um valor não real, mas uma média ponderada de dois outros preços, que elimina a necessidade de usar apenas o contrato com vencimento mais próximo e atenua distorções na série de preços.
  • O **Perfil de Mercado (Market Profile®)** é uma abordagem estatística para a análise de dados de preços, desenvolvida por J. Peter Steidlmayer. Organiza preço e tempo em uma representação visual da evolução do valor de mercado e é uma ferramenta de apoio à decisão que exige julgamento pessoal do usuário. Ele pode ajudar a definir o início ou a continuação da tendência de curto prazo e a rastrear a atividade de mercado de longo prazo.
  • O livro "Python Aplicado na Bolsa de Valores" serve como um guia para a construção de análises e indicadores, destacando a versatilidade do Python e sua comunidade consolidada no campo da ciência de dados e aprendizado de máquina. O livro é dividido em análise de portfólio, implementação de indicadores técnicos populares e desenvolvimento de estratégias de backtesting.
